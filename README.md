# Temperature-converter
A basic Java program that converts temperatures between Celsius and Fahrenheit wihout using If-statments.This a simple program that shows my learning of the Java language has no user input validation but is used if highlight a program that needs logical flow controls without using if,if else or else statments. 

Features:

- Convert a temperature from Fahrenheit to Celsius.

-Convert a temperature from Celsius to Fahrenheit.

-Accepts user input from the console.

-Outputs the converted temperature with one decimal place.

Prerequisites:

-Java JDK installed (version 8 or higher recommended).

-A code editor or IDE (e.g., VS Code, IntelliJ, Eclipse).

-Basic knowledge of running Java programs from the command line or IDE.
